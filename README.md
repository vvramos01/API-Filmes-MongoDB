# API de Filmes - Projeto Acadêmico

API RESTful desenvolvida com **Node.js**, **Express** e **MongoDB Atlas**, criada para fins de estudo.  
Permite cadastro e autenticação de usuários, além do gerenciamento de filmes e avaliações.  
Inclui um front-end simples em HTML e JavaScript para testes.

---

## Tecnologias

- Node.js  
- Express  
- MongoDB Atlas  
- JWT  
- Bcrypt.js
